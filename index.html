v1.11 增量存檔引擎

回合增量記錄
正常 RP Commit 只追加 Delta Journal 並更新 CURRENT。角色卡／劇情事件總檔不會因每一回合而整份重寫。v3.3.1 每次保存會自動刪除不再被 CURRENT／Packs／Journal／Archive／Checkpoint 引用的技術區塊，並把已處理訊息去重表限制在最近 128 筆。新建 Checkpoint 不再複製六份 Packs；還原／回滾／匯入前的自動快照只保留最近有限筆，避免備援本身越存越肥。Delta Journal 與 Cold Archive 是正式劇情歷史，不會被當技術垃圾刪除。

Cold Archive

封存＝搬移，不是複製
Controller 只允許封存已明確標成 RESOLVED／ENDED／CLOSED／COLD／ARCHIVE_READY，且沒有仍在作用後果與待檢查時間的事件。低頻本身不構成封存理由。

專案正式來源的本機備援快照

本機 0 / 6
正式規則仍以 ChatGPT Project 裡的資料來源為準。這裡只保存六份來源的 Safari 本機備援快照，不會寫進公開 index.html，也不會上傳到 GitHub。
維護時可以直接選 Project 下載的 TXT／YAML／JSON 原始檔；本頁會依文件內容辨識 slot、計算 SHA-256，並以內容雜湊去重。相同內容再次匯入不會製造第二份有效副本。

      
這裡存哪六份？
        
World Canon、Core Rules、Presentation、Character Design、Character Inspiration、Save Engine Policy。它們只是 Project 正式來源的本機備援快照。Runtime／Journal／Archive 是另一套本局活資料，不會塞進來源備援。
